# Stock Salmón

Aplicación Android y web para controlar los lomos de salmón de la cámara de frío.

## Funciones
- Configuración inicial del stock.
- Ingreso, retiro y recuento físico con validación de cantidades.
- Historial, filtros por fecha y exportación CSV.
- Calendario mensual y resumen diario.
- Umbral configurable y estimación de duración.
- Persistencia local sin cuenta ni conexión a Base44.

## APK
Cada push a `main` ejecuta GitHub Actions y genera el artefacto `StockSalmon-APK`.
